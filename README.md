## ❓ What is this calculator?
What I first ever started with is a calculator in Python and I kept making mistakes because of `float()` and stuff, but now I have created the ultimate calculator learning tool for Python (you probably have not and should not have heard this phrase).

## 🔥 What's in it
- **LICENSE**: Wow, the license.
- **calculator.py**: The calculator itself.
- **calculator-explained.py**: The calculator, but I explained everything. The explanation is still a bit blunt but I'm improving it!

## 💻 How to install
- **Straightforward:** Go to the releases tab and get the ZIP.
- **Torrents:** It does have a torrent for barely 20 kilobytes of information, you can use it, if you're into that kind of thing.
- **Compile from source:** Use the command in the `Compile from source` section.

## 🔙 Compile from source
Run the command to get the latest commit only:
```bash
git clone https://github.com/Rishav-KMCH/every-beginners-calculator --depth=1
```

You can remove `--depth=1` to get all the commits.

## ⌨ How to run
Run this once you've got the files:
```bash
python3 calculator(-explained).py
```

You can run the `-explained` one, but kinda pointless as it just gives the same output as the first one.
